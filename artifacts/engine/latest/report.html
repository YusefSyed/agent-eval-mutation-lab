Information-flow architecture

  1. 1 · PlanImmutable RunSpec creates 104 content-keyed tasks.
  2. 2 · ProjectOracle-only fields are removed before scoring.
  3. 3 · ScoreExplicit typed plugins return true, false, or unknown.
  4. 4 · ValidateThe coordinator rejoins finalized scores with truth.
  5. 5 · CommitOne writer records immutable results transactionally.
  6. 6 · ExportCanonical order erases worker scheduling noise.
Why no async service or distributed scheduler?

The benchmark is offline and the measured 104-task workload is tiny. Bounded threads exist to test schedule independence, not to claim speed. A network service, generic event sourcing, or mandatory async API would add surface area without stronger evidence.
